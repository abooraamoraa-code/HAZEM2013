منصة القوالب

الرئيسية استعراض القوالب أسعار الاشتراكات صفحة المطورين لوحة التحكم الدعم الفني

🛠️ زاوية المطورين وأكواد القوالب الجاهزة (HTML, CSS, JS)

مرحباً بك في مرجع المطورين الأساسي. هنا تجد الأكواد الخام والخالصة التي يمكنك نسخها ولصقها مباشرة في المفكرة (Notepad) لتعديل وتشغيل القوالب الثلاثة:

📦 1. كود القالب الأول: شركة ناشئة (HTML الأساسي)

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>قالب الشركة الناشئة</title>
    <style>
        body { font-family: Tahoma, sans-serif; background: #f9f9f9; padding: 20px; text-align: center; }
        .hero { background: #2563eb; color: white; padding: 40px; border-radius: 8px; }
    </style>
</head>
<body>
    <div class="hero">
        <h1>نصنع الحلول الرقمية لنمو أعمالك</h1>
        <button onclick="alert('تم تفعيل القالب بنجاح!')">ابدأ الآن</button>
    </div>
    <script>
        console.log("تم تحميل قالب الشركة الناشئة بنجاح عبر JavaScript الصرفة");
    </script>
</body>
</html>

🎨 2. كود القالب الثاني: بورتفوليو شخصي وسيرة ذاتية (JS & CSS تفاعلي)

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>بورتفوليو شخصي</title>
    <style>
        body { font-family: Arial; margin: 0; background: #1e293b; color: #fff; padding: 30px; }
        .profile-card { background: #334155; padding: 20px; border-radius: 10px; max-width: 400px; margin: auto; text-align: center; }
    </style>
</head>
<body>
    <div class="profile-card">
        <h2>مرحباً، أنا المطور</h2>
        <p>متخصص في تطوير واجهات الويب وتصميم القوالب البرمجية.</p>
    </div>
</body>
</html>

🛒 3. كود القالب الثالث: متجر إلكتروني مصغر (إدارة سلة التسوق بـ JS)

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>متجر إلكتروني مصغر</title>
</head>
<body>
    <h2>سلة المشتريات البرمجية</h2>
    <button onclick="addToCart()">أضف المنتج للسلة</button>
    <p id="cartStatus">السلة فارغة حالياً.</p>
    <script>
        function addToCart() {
            document.getElementById('cartStatus').innerText = "تمت إضافة المنتج بنجاح إلى السلة!";
        }
    </script>
</body>
</html>
